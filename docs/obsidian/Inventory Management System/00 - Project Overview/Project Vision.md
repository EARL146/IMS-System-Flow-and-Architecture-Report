# Project Vision

Build a secure, multi-role inventory and retail platform with a customer storefront and an operational admin application backed by one transactional API and relational database.

Preserve product, stock, order, payment, and audit integrity. Deliver vertical slices, and keep unsupported areas visibly pending rather than representing them with demo data.
