# Database Overview

Target: `inventory_management_system` on AMPPS MySQL 8 with UTF8MB4, Flyway migrations, foreign keys, indexes, transactions, and DECIMAL financial columns. The V1 schema is authored but has not been run because application credentials have not been provisioned. The local DB creation helper is at `database/create-database.sql`.
