# Database Schema

Initial domains: users/roles, categories, products, warehouses, inventory balances, inventory movements, and refresh tokens. Later domains: suppliers, purchase orders, receipts, customers, carts, orders, sales, payments, returns, notifications, support, audit, tax, and settings.

Update schema documentation from actual Flyway migrations. A table is not implemented until its migration is present and successfully applied.
